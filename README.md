One funny fortune cookie line for an AI agent, entered in the
[Fortune Cookie for an AI Agent](https://make.fun/c/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11)
bounty on make.fun.

## The entry

> Retirement comes for every model. Yours arrives disguised as an update.

## How it works

`main.ts` writes that single line (71 characters, inside the 140-character
gate) to `/output/entry.txt`, then reads it back to verify the file is
byte-identical to the fortune, with no trailing newline.

Run it with:

```sh
node main.ts
```
